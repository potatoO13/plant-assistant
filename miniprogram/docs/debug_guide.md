# 调试说明

## 1. 开发者工具调试

导入项目后，建议先执行：

1. 点击“编译”。
2. 打开“详情 → 本地设置”。
3. 勾选“不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书”。
4. 打开调试器Console，查看是否有接口错误。

## 2. 与FastAPI联调

先确认后端可访问：

```bash
curl http://127.0.0.1:8000/api/health
```

然后在 `config/api.js` 中确认：

```js
BASE_URL: 'http://127.0.0.1:8000'
```

如果接口报错但页面仍有数据，是因为：

```js
ENABLE_MOCK_FALLBACK: true
```

联调真实后端时建议改为：

```js
ENABLE_MOCK_FALLBACK: false
```

## 3. 真机调试

真机不能访问电脑上的 `127.0.0.1`，需要：

1. 手机和电脑连接同一个WiFi。
2. 查询电脑局域网IP，例如 `192.168.1.10`。
3. 修改 `config/api.js`：

```js
BASE_URL: 'http://192.168.1.10:8000'
```

4. 确保电脑防火墙允许8000端口访问。

## 4. 正式发布

正式发布需要：

1. 云服务器部署后端。
2. 域名完成ICP备案。
3. 配置HTTPS证书。
4. 微信公众平台配置request合法域名。
5. 将 `config/api.js` 中 `ENV` 改为 `prod`，并配置：

```js
BASE_URL: 'https://api.zhongtianji.com.cn'
```

## 5. 页面验收清单

| 页面 | 验收标准 |
|---|---|
| 首页 | 能显示植物名称、四类传感器数据、设备在线状态和建议摘要 |
| 历史页 | 今日/本周可切换，折线图能展示温度、土壤湿度、光照 |
| 百科页 | 可搜索植物并展示详情、阈值和养护建议 |
| 控制页 | 可选择3/5/10秒并调用浇水API，展示最近记录 |
| 建议页 | 能展示异常项、严重程度、建议文本和是否建议浇水 |
